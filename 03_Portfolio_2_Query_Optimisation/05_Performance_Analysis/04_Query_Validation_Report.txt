Overall Assessment
All eight baseline queries were executed and their outputs
were checked against the current sample dataset.

The QR-01 indexing experiment did not demonstrate a
performance improvement on this small dataset. The query
planner did not use the newly created customer-order index
in the observed post-index plan. Therefore, the experiment
does not establish that the index improves performance.

The reported results describe the current sample data and
should be reassessed if the dataset changes.
